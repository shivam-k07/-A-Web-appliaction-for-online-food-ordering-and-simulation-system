The Online Food Ordering Simulation System is a Python-based application that simulates the process of ordering food online. It allows users to browse food items, add items to their cart, place orders, and view order details.

Features

User registration and login

Display available food items

Select food items

Add items to cart

Update cart

Calculate total bill

Place food orders

View order details

Manage food items and orders
